# Mastitis Detector

Система раннего выявления мастита у коров по данным датчиков (активность,
жвачка, температура). Загружаем данные по стаду и получаем список коров,
которых стоит осмотреть в первую очередь. Система только подсказывает,
диагноз ставит ветеринар.

## Кто чем занимается

## Как запустить

Бэкенд (нужен Python):

```
cd backend
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

Документация и проверка запросов: http://localhost:8000/docs

Сайт (нужен Node.js):

```
cd frontend
npm install
npm run dev
```

Сайт откроется на http://localhost:5173

## Как отправлять свои изменения

В `main` лежит рабочая версия, поэтому правки мы отправляем не туда напрямую,
а через свою ветку и Pull Request. Выглядит это так:

1. Забрать свежую версию: `git checkout main`, затем `git pull`
2. Создать свою ветку: `git checkout -b feature/что-делаю`
3. Поработать, затем `git add .` и `git commit -m "что сделано"`
4. Отправить ветку: `git push -u origin feature/что-делаю`
5. На GitHub нажать **Compare & pull request**, попросить кого-то из команды
   посмотреть, затем **Merge**

Что помогает не запутаться:
- одна ветка равна одной задаче, так проще смотреть и объединять;
- перед `git add .` загляните в `git status` и убедитесь, что там нет лишнего
  (`.venv`, `node_modules`);
- сохраняйте файлы в кодировке UTF-8, иначе русский текст сломается.

## Общий договор между сайтом и сервером

Файл `backend/app/schemas.py` описывает, какие данные ходят между сайтом и
бэкендом. Если его нужно изменить, сначала напишите в чат, потому что это
затрагивает всех троих.
